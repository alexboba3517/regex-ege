# regex-ege

Образовательный сайт для изучения регулярных выражений в Python — с прицелом на задание 24 ЕГЭ по информатике.

Материал разбит на последовательные блоки теории и практики: от базового синтаксиса (`.`, `[abc]`, квантификаторы, группы) до продвинутых приёмов (`re.finditer`, просмотр вперёд/назад, обратные ссылки). После каждого блока теории сразу можно закрепить его в практике по той же теме.

## Стек

Python + Flask на бэкенде, обычные HTML/CSS/JS на фронтенде — без React, без сборщиков. Контент (теория, упражнения) хранится в JSON-файлах, без базы данных.

## Как запустить локально

```bash
python -m venv venv
venv\Scripts\activate        # на Windows; на macOS/Linux: source venv/bin/activate
pip install -r requirements.txt
python app.py
```

Откройте `http://127.0.0.1:5000`.

## Структура проекта

```
app.py               # Flask-приложение и маршруты
content/
  theory.json         # блоки и темы теории
  exercises.json       # блоки и упражнения практики
templates/            # Jinja-шаблоны
static/               # CSS и JS
```

## Как проверяются упражнения

- Упражнения на `re.fullmatch` и `re.finditer` — пользовательский regex реально выполняется на сервере (это безопасно: компилируется только сам шаблон, никакого произвольного кода).
- Упражнения «напишите программу целиком» **не выполняют** присланный код — проверяется только его структура (есть ли `import re`, нужный вызов, `print`, используется ли строка из условия) плюс, если шаблон явно виден в коде, честно проверяется его результат.

## Прогресс

Прогресс по упражнениям хранится в `localStorage` браузера — без аккаунтов и без сервера. Сбросить его можно кнопкой ↺ в шапке сайта.
